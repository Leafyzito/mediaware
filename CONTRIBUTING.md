# Contributing
This file is dedicated to those who want to contribute to this plugin, adding more features or such.

> Do note that when contributing, you must agree that 100% of the authored content belongs to you, and as such you should disclose any AI usage or where you got the original code from.

That being said, make sure to follow the guidelines on contributing followed:

- If you're going to submit an issue, make sure you checked for updates that might have fixed this issue and updated your system to its latest version.
- For any pull requests made, make sure to also be descriptive on what it does and double check your code is "clean", as in no parts of it are obstructed or could lead to more issues than if they were not considered on the first place.
- For both issues and pull requests you write, make sure to be descriptive on the title, and to explain the issue as well as including your chat client's version, making sure you include the git branch if you've compiled it, as well as the operating system you're using the chat client on.

Feel free to suggest changes to this file, as it will be the base of any future contributors of this plugin and its features, and thank you for your interest on contributing to the plugin.
